# podman-navigator
**Интерактивная шпаргалка по Podman** — 25+ команд, Pods, интеграция с Kubernetes, Systemd, Rootless режим.

[🌐 Открыть шпаргалку](https://iso-hallow.github.io/podman-navigator/) RU/EN

## ✨ Особенности

- 🔍 **Мгновенный поиск** — по командам, описаниям
- ⭐ **Избранное** — сохраняйте нужные команды (localStorage)
- 🧊 **Pods** — главная фишка Podman (группы контейнеров)
- ☸️ **Kube & Systemd** — генерация YAML и автозапуск
- 📊 **Визуальные схемы** — Daemonless архитектура, Что такое Pod, Workflow
- 🌓 **Тёмная/светлая тема** — по кнопке или F2
- 🌐 **Русский / English** — переключатель языка
- 📤 **Экспорт** — в JSON или Markdown
- ⌨️ **Горячие клавиши** — `/` поиск, `Esc` сброс, `F2` тема

## 🎯 Чем отличается от Docker шпаргалки?

| Docker Navigator | Podman Navigator |
|----------------|------------------|
| 88 команд | 25+ ключевых команд |
| Daemon-based | **Daemonless** |
| Требует root | **Rootless by default** |
| Нет pods | **Pods (как в K8s)** |
| Нет генерации YAML | **Kubernetes YAML экспорт** |
| Нет Systemd | **Systemd интеграция** |
